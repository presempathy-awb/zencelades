# Zencelades logo

Vector masters for the Zencelades mark and wordmark. Nothing on the site uses them yet.

The mark is an ice moon cut into four shards by a Z-shaped fracture. The fracture shows
the warm interior, after the heat Cassini measured along Enceladus's tiger stripes, and
a plume vents from its upper corner.

| File | Use |
|---|---|
| `zencelades-lockup.svg` | Mark and wordmark side by side, for dark grounds. The default. |
| `zencelades-lockup-stacked.svg` | Mark above wordmark, for dark grounds. |
| `zencelades-mark.svg` | Mark alone, for dark grounds. |
| `zencelades-*-on-light.svg` | The same three with deep-ocean shards and ink, for light grounds. |
| `zencelades-icon.svg` | Mark without the plume on a rounded ocean tile, with a bolder cut for favicon sizes. |
| `zencelades-mark-mono.svg`, `zencelades-wordmark-mono.svg` | One colour. They paint in `currentColor`, so they take the ink of whatever embeds them. |

Colours: ocean ground `#0a1922`, ink `#edf4f4`; ice `#ffffff` to `#1a6a8b`; heat
`#5a31f4`, `#ee3f8e`, `#ff8a3c`, `#ffd166`.

The wordmark is drawn from lines and arcs. No font is embedded or outlined, so the files
carry no font licence.
