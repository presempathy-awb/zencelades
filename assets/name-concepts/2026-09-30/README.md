# 22 logo, infographic and explanation sheets

Created September 30, 2026 with the built-in image_gen tool.

Open `index.html` to browse the full set. Each PNG combines a logo/wordmark, visual name breakdown and explanation. Logos are embedded raster concept artwork, not separate vector masters. Supplied names and spellings are preserved. `prompts.json` contains the exact generation prompts; `manifest.json` records source files, dimensions and SHA-256 hashes.

Source context: `docs/intent.md`, `assets/naming-explanations.json`, `assets/naming-explanations-final.json`, and `site/naming/report.json` in the thatsnozorb project. New interpretations are explicitly labeled proposed readings, not established word origins.
