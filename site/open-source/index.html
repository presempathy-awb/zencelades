Tools, authorship & provenance

Show the work behind the wonder.

Zencelades is developed with open-source software, human design decisions and AI assistance. Those contributions have different responsibilities and different rights.

This page separates the software used to make the project, the source code available to inspect, and the images and media shown in it. Public access alone does not grant permission to reuse every file.

Where AI contributes.

OpenAI’s Codex assists with implementation, research organization, documentation and verification work in this project. Andrew directs the concept, equipment constraints, configuration choices and public presentation.

Some concept boards and naming illustrations were created with image-generation tools. The original supplied boards are catalogued as ChatGPT images, and the naming gallery records its use of the built-in image generation tool. Exact model versions are not established by those records.

Generated images are labeled as concepts. Their embedded prices, dimensions, safety statements and historical event captions are not verified specifications.

Models and engineering are different claims

The current schematic model images are rendered from explicit geometry and source scripts, including Blender’s Python API. The interactive studio uses Babylon.js. These are reproducible model studies, distinct from image-generated concept paintings.

AI assistance and reproducible geometry do not establish structural capacity, equipment suitability or approval for a person to occupy the installation. Human fabrication decisions, qualified review and physical testing remain necessary.

Optional live participant imagery is a proposed feature, not evidence of a deployed camera system or consent to record visitors.

What the licenses cover.

Archived project source
The v3 and v4 project packages each include an MIT license expressly limited to original project-side source in that revision. Their license files exclude third-party dependencies, personal likenesses, NASA/JPL media and prior generated artwork.
Current website source
The inspected repository has no repository-wide root license file. The archived MIT notices should not be read as automatically licensing every later website file, model or contribution. Consult an explicit file/package license or obtain permission before reuse.
Third-party software
Every dependency retains its upstream license and notice requirements. The table below records the direct cockpit dependencies; it is not a complete transitive software bill of materials or a redistribution audit.
Scientific media
NASA/JPL imagery and other scientific sources retain their source-specific credits and use conditions. Procedural ice textures are artistic approximations; a generated image caption does not establish NASA provenance or endorsement.
People and concept art
Software licenses do not grant rights to someone’s likeness or to every supplied or generated image. Check the individual asset’s provenance and intended use before republishing.

The project’s asset and publishing helpers use Python. The archived design packages additionally document NumPy, Pillow, PyYAML and optional CAD, drawing and capture tools. Their accompanying notices describe that separate toolchain; they are not all shipped as website runtime dependencies.

The pages use locally available Georgia and Avenir/Helvetica font families through CSS fallbacks. No font files are bundled by these pages, and those fonts are not claimed as open-source project assets.
