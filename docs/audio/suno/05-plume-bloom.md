# Plume Bloom

ID: `music-05`  
Provider: Suno  
Status: prompt ready; audio not generated or auditioned  
Use: Plumes / energetic reveal  
Tempo/key targets: 120 BPM, D minor  
Mix family: 120 BPM

## Suno controls

Custom mode; Instrumental on; Lyrics empty. Choose an available model and record
its exact version. Initial audition settings: Weirdness 35%, Style Influence
85%. These are proposed comparison baselines, not measured optima.
Audio Influence is unused without an audio reference. Aim for 3–4 minutes in
editing; exact duration, tempo, key, phrase lengths and loop seams are not guaranteed.

## Style prompt — copy this field

```text
Instrumental cinematic breakbeat, 120 BPM, D minor, firm 4/4 phrasing. Buoyant broken drums, tight rounded bass, luminous arpeggios and rising filtered synth chords. A three-note rising motif expands into wide harmonies as icy plumes catch the light. Exhilarating and playful, with a controlled lift rather than a punishing drop. Start with a clean percussion intro, build through repeating phrases, open into a suspended melodic break, bring back the groove, then finish with an extended drums-and-atmosphere outro.
```

## Exclude — separate field

```text
vocals, spoken words, sirens, explosions, festival horns, hardstyle kicks, abrupt stop
```

## Production and acceptance

One plume accent per visual burst group, with a cooldown. Do not retrigger on every animation frame.

Audition a baseline before increasing settings. Keep source song ID, model,
prompt revision, settings and the selected take together. Measure actual tempo,
key, integrated loudness and true peak; mark clean mix-in/mix-out bars after
listening. Preserve the original download and make runtime derivatives separately.
A reference to the shared motif is direction, not a guarantee that independently
generated songs will share the same melody. If that continuity matters, use an
approved original audio reference or arrange the motif in post-production.
