## Suno controls

Custom mode; Instrumental on; Lyrics empty. Choose an available model and record
its exact version. Initial audition settings: Weirdness 45%, Style Influence
75%. These are proposed comparison baselines, not measured optima.
Audio Influence is unused without an audio reference. Aim for 3–4 minutes in
editing; exact duration, tempo, key, phrase lengths and loop seams are not guaranteed.

## Style prompt — copy this field

```text
Instrumental playful electro-funk, 120 BPM, D minor, crisp 4/4. Rubber-band synth bass, dry claps, compact drum-machine grooves, plucked marimba-like synths and short call-and-response phrases. A cheeky three-note rising motif hops between registers like a tiny rover discovering a dance floor. Tactile, curious and lightly mischievous, never cartoonish. Keep the groove steady, alternate sparse rhythmic passages with bright melodic answers, leave a short beatless reset, then return and finish with an extended rhythm-only outro.
```

## Exclude — separate field

```text
vocals, spoken words, novelty sound effects, comic boings, abrasive leads, tempo changes
```

## Production and acceptance

Musical movement should follow explicit interaction cues later, not camera-derived mood or emotion guesses.

Audition a baseline before increasing settings. Keep source song ID, model,
prompt revision, settings and the selected take together. Measure actual tempo,
key, integrated loudness and true peak; mark clean mix-in/mix-out bars after
listening. Preserve the original download and make runtime derivatives separately.
A reference to the shared motif is direction, not a guarantee that independently
generated songs will share the same melody. If that continuity matters, use an
approved original audio reference or arrange the motif in post-production.
