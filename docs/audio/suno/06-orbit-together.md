Instrumental melodic deep house, 120 BPM, F major, steady four-on-the-floor groove. Supple round kick, elastic bass, warm Rhodes chords, crisp understated shakers and a luminous three-note rising synth motif. Feels like friends circling a glowing moon on a warm shoreline: generous, hopeful and communal. Smooth repeating sixteen-bar phrases, a spacious percussion-only opening, one gentle harmonic breakdown, an uplifting return and a long mix-friendly outro. Clear low end, restrained peaks, plenty of space between melodic gestures.

## Production and acceptance

Suggested core DJ bed. Favor one bassline at a time during a blend; confirm phrase boundaries by ear.

Audition a baseline before increasing settings. Keep source song ID, model,
prompt revision, settings and the selected take together. Measure actual tempo,
key, integrated loudness and true peak; mark clean mix-in/mix-out bars after
listening. Preserve the original download and make runtime derivatives separately.
A reference to the shared motif is direction, not a guarantee that independently
generated songs will share the same melody. If that continuity matters, use an
approved original audio reference or arrange the motif in post-production.
