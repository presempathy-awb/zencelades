## Style prompt — copy this field

```text
Instrumental ambient post-rock and warm downtempo, 72 BPM, F major, a barely-there 4/4 pulse. Soft electric-piano notes, gently bowed guitar swells, brushed cymbals and luminous analog pads. The three-note rising motif becomes a slow reassuring answer, like returning from an impossible moon to familiar salt air. Peaceful, human and quietly grateful. Start with an exposed pad, add a small warm melody, reach one restrained swell, and gradually dissolve into a long clean atmospheric tail with room for conversation.
```

## Production and acceptance

Use for voluntary exit and idle reset. A hard Stop must mute immediately rather than waiting for this song.

Audition a baseline before increasing settings. Keep source song ID, model,
prompt revision, settings and the selected take together. Measure actual tempo,
key, integrated loudness and true peak; mark clean mix-in/mix-out bars after
listening. Preserve the original download and make runtime derivatives separately.
A reference to the shared motif is direction, not a guarantee that independently
generated songs will share the same melody. If that continuity matters, use an
approved original audio reference or arrange the motif in post-production.
